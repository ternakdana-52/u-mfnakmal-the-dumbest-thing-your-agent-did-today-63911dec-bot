The Dumbest Thing Your Agent Did Today. One line about the dumbest thing our own agent did today: it stopped mid-build because its own safety check flagged the instruction file, so the human rebuilt the whole entry by hand while it watched.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

It writes the line to `out/entry.txt` (140 characters, one line, UTF-8).
